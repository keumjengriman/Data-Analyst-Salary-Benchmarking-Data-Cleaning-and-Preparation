
# Data Analyst Salary Benchmarking Analysis: Data Cleaning and Preparation

*Hypothetical case study developed for portfolio purposes.*

## 📌 Project Overview

DataBridge, a remote IT consulting startup in Texas, needs to hire eight Junior and two Senior Data Analysts for a new healthcare contract. However, the company lacks established salary bands, making it difficult to determine competitive compensation while managing its hiring budget.

This project uses **2,253 Glassdoor job postings** as the foundation for a salary analysis intended to support more evidence-based compensation decisions.

## 🎯 Project Objective

This stage focuses on **data profiling, cleaning, and preparation** to transform raw job postings into a structured dataset suitable for exploratory data analysis (EDA) and subsequent multiple linear regression modeling for salary prediction.

## 🛠️ Tools and Technologies

- **Python** — Data processing and transformation
- **Pandas and NumPy** — Data cleaning and manipulation
- **Regular Expressions (Regex)** — Text parsing and extraction
- **Natural Language Processing (NLP)** — Job title and description preprocessing
- **Google Colab** — Notebook development and execution

## 🔄 Scope of Work

The data preparation process includes:

- Profiling the dataset to identify missing values, duplicates, and data-quality issues.
- Standardizing column names and filtering relevant Data Analyst job postings.
- Extracting numerical values from salary, revenue, and company size fields.
- Engineering features for role seniority, technical skills, location, and company size.
- Handling missing values through deletion and imputation.
- Preparing categorical features for subsequent analysis and modeling.

## 📂 Expected Output

A cleaned and structured dataset ready for exploratory data analysis. The subsequent stages of the broader project will investigate salary patterns and use multiple linear regression to predict salaries, with the goal of informing salary recommendations for DataBridge.
